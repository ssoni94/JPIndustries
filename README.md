# JP Industries

Android starter project for generating QR labels and printing them on a TSC printer.

Open this folder in Android Studio:

`/Users/sagarsoni/Downloads/JPIndustries`

## Included

- Native Android app module
- QR code generation using ZXing
- Starter label form
- TSPL command builder for TSC printers
- Bluetooth permissions in the manifest

## Next Steps

- Add Bluetooth printer discovery and connection
- Send the generated TSPL command bytes to the selected printer
- Adjust label size, text fields, and QR position for your physical label roll
